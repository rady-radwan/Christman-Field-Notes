# Christman Field Observations

Field observations for project teams. Someone on site:
1. takes photos and marks them up (arrows, boxes, circles, clouds, text)
2. gives the observation a title, type, category, priority, location and due date
3. describes it in text or a voice message, and assigns people
4. publishes it; it gets a number like NCMC-MEP-001

The team discusses it with text, voice messages and marked-up photos. The reporter or an admin
moves it through Open, In Progress, Pending Verification and Resolved (or On Hold / Voided).
A dashboard shows totals, overdue items, and open items by category and by person.

Built with Flutter, so one codebase makes the Windows, Android and iOS apps.
Windows ships first.

## Install on Windows

1. Open the **Releases** page of this repository (or the latest run under **Actions**).
2. Download `ChristmanFieldNotes-Setup-x.y.z.exe` and run it. No admin rights are needed.

Windows may show a SmartScreen warning because the installer isn't code-signed yet. Click
**More info > Run anyway**.

## How it works

| Area | What it does |
| --- | --- |
| **Open notes** | Active and Suspended notes only. Sorted by priority, then newest, then latest reply. Category filter, plus an "Assigned to me" toggle. |
| **By date** | All notes in four groups: This week, Past week, Earlier this month, Older. Solved and deactivated notes are grayed out. |
| **By category** | The full history of one category, with open notes first. |
| **Note page** | Photos, issuer comment, details, status buttons (admin or issuer only) and replies with photos. |
| **Admin** | Approve sign-ups, make admins, remove people, add people to projects, edit projects and categories. |
| **Themes** | Light, dark, or the system setting, using Christman copper and black. |

### Rules

- **Anyone can look around without signing in**, including notes, photos and replies. Adding or changing anything asks them to sign in.
- Anyone approved can create a note. A new note starts as **Active**.
- Only the admin or the issuer can change a note's **status** or **priority**.
- Only an admin can **deactivate** a note. It stays visible but grayed out.
- The issuer can delete his note until someone replies. After that, only an admin can delete it.
- A note with nobody assigned is a **general note** for everyone.
- The bell shows new notes and replies that involve you.

## Data

- **No server connected:** everything is saved on that computer, in
  `%APPDATA%\The Christman Company\Christman Field Observations\FieldNotes`. The first account created becomes the admin.
- **Shared server:** see [SERVER-SETUP.md](SERVER-SETUP.md) (Supabase, about 10 minutes).

## Development

Pushing to `main` makes GitHub Actions:

1. analyze the code and run the tests
2. build the Windows app
3. package it with Inno Setup

Pushing a tag such as `v0.1.0` also publishes a GitHub Release with the installer.

To run it locally (with Flutter installed):

```
flutter create --platforms=windows,android,ios --org com.christman --project-name christman_field_notes .
flutter run -d windows
```

The platform folders (`windows/`, `android/`, `ios/`) are generated by `flutter create` and
aren't committed yet.

```
lib/
  main.dart              start-up, picks this computer or the server
  models.dart            Note, Reply, Project, AppUser, Priority, NoteStatus
  theme.dart             light and dark colors
  data/                  storage: on this computer (LocalRepo) or on Supabase (SupabaseRepo)
  state/                 app state, filters, sorting, permissions, saved settings
  screens/               sign in, home (phone and Windows layouts), note page, forms, admin
  editor/                photo markup editor
  widgets/               shared pieces
supabase/schema.sql      server tables, security rules and photo storage
installer/               Windows installer script
```
